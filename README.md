# IPL-Project-
**IPL Data Analysis Project**  Analyzed Indian Premier League (IPL) data using SQL to explore team performance, player statistics, match results, batting and bowling performance, and season-wise trends. Used SQL queries, joins, and aggregate functions to generate meaningful insights and identify top-performing players and teams.

IPL Auction Data Analysis

Objective: 
To analyze IPL auction data and identify player pricing trends, team spending patterns, and player category-wise costs.

Data Collection – Import the IPL auction dataset.
Data Understanding – Explore rows, columns, and data types.
Data Cleaning – Handle missing values, duplicates, and outliers.
EDA – Analyze player types, teams, and auction costs.
Data Visualization – Create charts using Matplotlib and Seaborn.
Insights & Conclusion – Identify spending patterns and key findings.
